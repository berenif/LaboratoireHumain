# Bounded actual-WASM recovery adaptation

## Result: rejected

The single frozen-feature correction candidate did not improve the original BACK
case. Its longest measured feet-only, loaded, upright, low-motion interval stayed
at zero and it reached the unchanged 25-second deadline. The required improvement
of at least 80 native samples on **both** frozen BACK states was not met.

The narrowly related heldout did improve, from 15,608 to 17,670 samples over the
same fixed 25-second observation window. It used the same initial BACK fixture
with passive physical settling continued to native 560 instead of 480. This was
one predeclared construction, admitted before its policy performance was observed;
it is not an independent-fall generalization claim. No replacement case was sought.
Belly retained the original 800-sample gate and a subsequent 30-second hold.

See [compact audited evidence](../evidence/getup-wasm-adaptation-2026-10-20.json).
No trained candidate is embedded, enabled, published, or promoted.

## Controller boundary

The experiment-only `getup-policy-adaptation-experiment` feature adds a local head
on the frozen original 118-input SLOW network's second 1,024-wide ReLU features.
Its correction is `c = tanh(Wf + b)` in qpos order. Applied residuals are
`tanh(original_raw + 0.05*c)`. For an exactly zero correction, original Rust/WASM
action words are copied directly; logits are never reconstructed with `atanh`.
SAC replay, critics and entropy operate on `c`, not the transformed residual.

The existing controller owns WEAK forecasting, current/+5 reference observations,
reference indexing, the 40 Hz hold, 800 Hz PD, actuator permutation/clipping,
original impact deadline, standing counters/anchors and terminal balance transfer.
The first 20-native source decision stayed original on every training/evaluation
branch; the head began at the following decision boundary. No root/body state,
gain, solver, reference target, or acceptance threshold was changed.

Active-adaptation checkpoints use a schema-4 envelope around the intact existing
checkpoint payload, including the exact-bit root-translation sidecar. Older
builds reject them. The optional controller field is omitted when inactive.
The checkpoint stores the head, pending/held correction receipt and original
controller/world state. Exact off/zero replay covered 2,440 native samples;
uninterrupted/checkpoint-resumed replay covered 2,240 samples. The adapter is
single-cycle only: the existing completed-cycle reset drops the installed head.
Adapted repeated-fall behavior is unqualified.

## Frozen learning and budget

- One CPU seed, 8,192 new source decisions; replay 8,361 of a 10,240-entry cap
- 169 fresh successful belly transitions; at least 25% rehearsal items per batch
- Batch 128; 256 critic-only updates, then 256 critic/actor updates; one final head
- Fixed discount `exp(-0.025/25)`, retaining `exp(-1)` over the 25-second horizon
- Measured success/deadline failure, bounded supported-upright potential, correction
  and slew penalties; no physical COM reward toward the canonical 1.4 m sentinel
- Source-to-standing tails receive their discounted terminal reward with zero
  bootstrap; administrative collection truncation remains separate from failure
- 364,180 charged integrations: 330,620 real, 28,540 forecast, and a conservative
  5,020 charge for an interrupted outstanding harness call; cap 600,000
- The original 60-minute deadline was preserved through mechanical harness fixes;
  collection, evaluation, updates, compile pauses and final audit fit in 17 minutes

The retained older observer lacked three newer read-only fields. Parity projected
only those absent fields for old/current comparison; current off/zero comparisons
remained complete. A packet-prefix metric bug and terminal-tail accounting were
fixed before learning. Successful BACK observations were initially censored at the
first success; before updates, evaluation was corrected to a fixed impact+25-second
endpoint using the exact saved world. The single candidate's same-world extension
used the same head, epoch, reference and terminal controller. All extra physics was
charged separately and aggregated under the original cap. Censored reports remain
local and are superseded for acceptance by the fixed-window audit.

The belly holds preserved all original native predicates and counters for 24,000
additional samples. Candidate maximum original foot-origin drift was 1.373 mm;
maximum anchored material-point excursion was 2.297 mm. The separate limits remain
10 mm and 20 mm. Excursion is not cumulative material travel.

## Local tools and limits

- `getup-wasm-adaptation-protocol.mjs`: actual-WASM JSONL bridge and inclusive ledger
- `train-getup-wasm-adaptation.py`: bounded CPU collection/SAC; refuses a reused
  training output; its first-success metrics require the fixed-window audit
- `continue-getup-wasm-evaluation.mjs`: same-world fixed-25-second continuation
- `finalize-getup-wasm-adaptation.py`: read-only artifact/counter/metric audit
- Focused Python, JavaScript and Rust tests exercise math, replay tails and zero-head
  behavior. The broader historical physical/release suite is not claimed passing.

Only code and compact evidence are retained in Git. Head weights, replay, learner
state and physical checkpoints stay local. Source-policy redistribution rights
remain unresolved. These are Node-hosted WASM results, not candidate browser,
mobile, repeated-fall or public-release qualification. The negative experiment is
closed; no wider head, correction scale, gain, horizon or candidate search followed.

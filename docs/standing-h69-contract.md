# H69 — isolated warm start with a bounded cache budget

H66 passes the short physical screens but costs 1.72–1.88 seconds per step.
H67 and H68 show that previous commands and preceding task-response columns can
provide bounded starting points, with incomplete task convergence. Test their
combination in a separate process-local diagnostic while the original H66 long
histories continue unchanged.

Copy the H66 preview implementation into an evidence-owned candidate. A
process-local loader replaces only that module for this candidate. Preserve
the original module's resolution context, every dependency and all production
files. Save the exact candidate, loader, runner, original-module digest,
environment selection and before/after hashes with every invocation. The
ordinary source fingerprint alone does not describe an injected candidate.

At each eligible step, test the preceding chosen torque bias clipped to current
ceilings. Use it only if the predicted output meets every physical speed guard
and the 0.4 rad/s foot guard, and either the zero-bias baseline fails that guard
or the unchanged tracking/pelvis objective improves. Evaluate the original
angular and arm stages from the selected seed.

Use one horizontal search iteration per step. Build its fourteen-axis response
matrix on the first needed step, after sixteen steps, or when axis identities,
native gains/ceilings or load-bearing contact-segment membership change.
Otherwise reuse the cached matrix. Keep the original normalization, damped
solve, native-cap trust rule, six backtracking fractions and feasible improving
probe selection when fresh probes exist. Clear cache and previous bias when
the preview becomes ineligible; invalidate the matrix after a coupled fallback.
The original full coupled speed fallback remains available.

Keep the 0.2 mm/s tracking deadband and bounded pelvis targets unchanged, and
record every miss. The reduced search budget does not alter physical acceptance.
Save warm-seed decisions, cache provenance, full candidate metrics/digests and
all exact chosen/live body comparisons. Count queries and runtime separately;
concurrent timing is not a controlled frame-rate benchmark.

First require an exact thirty-step H66 replay with the candidate disabled.
Then screen all three original headings for 2+10 seconds under the same physical
criteria. No long evaluation or production adoption follows unless the complete
short screens pass. H66's active source and histories remain frozen.
